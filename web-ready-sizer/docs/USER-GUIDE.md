# دليل الاستخدام - Web-Ready Sizer

## المفاهيم الأساسية

| المصطلح | المعنى |
|---|---|
| **rem** | وحدة CSS نسبية لجذر المستند. عند الأساس الافتراضي: `1rem = 16px`. |
| **px** | البكسل المستخدم داخل Illustrator. |
| **pt** | النقطة (وحدة Illustrator للخطوط). `1pt = 1.333px` عند 96 DPI. |
| **كلاس Tailwind** | مثل `w-20` (= 5rem = 80px) أو `text-xl` (= 1.25rem = 20px). |
| **نقطة توقف** | عرض شاشة في التصميم المتجاوب: sm 640، md 768، lg 1024، xl 1280، 2xl 1536. |

---

## تبويب التحجيم

### اختيار الوحدة

- **rem** — اكتب القيمة بالـ rem: `5rem` أو `5` أو `1.5rem`.
- **Tailwind** — اكتب الكلاس أو رقمه: `w-20` أو `20`.
- إذا كتبت رقماً بلا وحدة في وضع rem، يُفسَّر كـ rem؛ في وضع Tailwind يُفسَّر كرمز بعد `w-`.

### حقول العرض والطول

| الإدخال | الناتج (أساس 16px) |
|---|---|
| `5rem` | 80px |
| `1.5` | 24px |
| `w-20` | 80px |
| `w-3.5` | 14px |
| `80px` | 80px |
| `h-6` في حقل الطول | 24px |

السطر أسفل الحقل يعرض دائماً: **الكلاس = px = rem** حتى تتأكد قبل التطبيق.

### حقل حجم الخط

يظهر فقط عند تحديد TextFrame. يقبل:

| الإدخال | الناتج |
|---|---|
| `1rem` | 16px = 12pt |
| `text-xl` | 20px = 15pt |
| `18pt` | 24px |
| `24` | 24px |

التطبيق يحوّل px إلى pt تلقائياً قبل الكتابة إلى Illustrator.

### الخيارات

| الخيار | الأثر |
|---|---|
| **تقريب لأقرب قيمة Tailwind** | `23px` → `24px` (w-6). يضمن ألا يبقى arbitrary value. |
| **الحفاظ على النسبة** | إن غيّرت العرض يتكيّف الطول بنفس النسبة (والعكس). |
| **تطبيق على كل المحدد** | يعالج كل عناصر التحديد لا الأول فقط. |
| **تثبيت الزاوية العلوية اليسرى** | يمنع انزلاق العنصر عند تغيير مقاسه. |

### الاختصارات

- `Enter` داخل أي حقل → تطبيق.
- `Esc` → إغلاق النوافذ المنبثقة.
- الأزرار `+`/`−` في الحقل تزيد/تنقص بمقدار 4px.

### الاختيار السريع

صفّ من أزرار جاهزة. في وضع rem تعرض قيماً بـ rem، وفي وضع Tailwind تعرض كلاسات `w-*`. الضغط يملأ الحقل الأخير الذي عدّلته (عرض أو طول).

## تبويب المفتش

يعرض خصائص العنصر المحدد ويولّد الكود. لا يعدّل العنصر — للقراءة والنسخ فقط.

### الأبعاد والموضع

لكل قيمة: px و rem والكلاس المقابل. الموضع X/Y يقابل `left-[...]` / `top-[...]`.

### الألوان

- **سواتش** مرئي + HEX.
- **أقرب كلاس** محسوب بخوارزمية CIEDE2000 على 242 لوناً في باليت Tailwind.
- **مؤشر الثقة**: `exact` (ΔE ≤ 2) / `close` (≤ 5) / `approximate` (≤ 10) / `distant`.

الألوان غير الصالحة (تدرّجات، patterns) تُعرض بدون كلاس.

### الطباعة (للنصوص فقط)

| الخاصية | التحويل |
|---|---|
| الحجم | pt → px → أقرب `text-*` |
| الوزن | من اسم الخط/style → `font-*` |
| حالة الأحرف | ALL CAPS → `text-uppercase` |
| التباعد | tracking/1000 → `tracking-*` |
| ارتفاع السطر | نسبة leading/size → `leading-*` |

### المخرجات

أربعة تنسيقات:

- **Tailwind** — الكلاسات فقط، مفصولة بمسافة.
- **HTML** — عنصر كامل مع `class` و`data-w`/`data-h`.
- **CSS** — قاعدة CSS باسم صنف مولّد.
- **الكل** — الثلاثة معاً.

أزرار: **نسخ الكل** و**حفظ ملف**. وحفظ الملف يفتح مربع حوار Illustrator.

> نسخ الكلاس المفرد: زر `copy` بجانب أي صف.

## تبويب اللوحات

### نقاط التوقف الرسمية

| الاسم | العرض | الاستخدام |
|---|---|---|
| sm | 640px | جوال أفقي |
| md | 768px | تابلت عمودي |
| lg | 1024px | تابلت أفقي / لابتوب صغير |
| xl | 1280px | سطح مكتب |
| 2xl | 1536px | سطح مكتب كبير |

### الخيارات

- **الارتفاع الافتراضي** — ارتفاع كل artboard جديد (افتراضي 900px).
- **المسافة بين اللوحات** — الفجوة بالبكسل (افتراضي 80).
- **الترتيب** — أفقي (بجانب بعضها) أو عمودي (تحت بعضها).

### الإنشاء

- **إنشاء** بجانب نقطة توقف → لوحة واحدة.
- **إنشاء كل نقاط التوقف** → الخمسة دفعة واحدة بترتيب متتابع بلا تداخل.

كل لوحة تُسمّى `Tailwind <name> (<width>px)`.

### اللوحة النشطة

يعرض اللوحة النشطة حالياً وأقرب نقطة توقف لعرضها. زر **تغيير الحجم** يضبط عرضها على عرض نقطة التوقف الأقرب (الارتفاع يبقى كما هو).

### نقاط مخصصة

- زر **إضافة نقطة مخصصة** يفتح نافذة (اسم + عرض).
- تُحفظ في `localStorage` وتظهر ضمن قائمة الإنشاء فور الإضافة.
- زر الحذف يزيلها من القائمة.

## التصدير

من تبويب المفتش → **تصدير التحديد**:

| التنسيق | الاستخدام |
|---|---|
| Tailwind HTML | صفحة HTML كاملة مع CDN لـ Tailwind — للمعاينة السريعة أو اللصق في مشروع |
| CSS | قواعد CSS خام — لمشاريع لا تستخدم Tailwind |
| Tailwind classes | قائمة كلاسات مفصولة بأسطر — لصق في React/Vue |
| Tailwind config | امتداد `theme.extend` للـ config |
| Design Tokens JSON | صيغة Design Tokens لأدوات التزامن |

خيارات:

- **استخدام rem بدل px** في قواعد CSS.
- **إضافة dir=rtl** في HTML.
- **ضغط المخرجات**.

الأزرار: نسخ / حفظ (حفظ يستخدم مربع حوار Illustrator).

## الإعدادات

| الخيار | التفاصيل |
|---|---|
| اللغة | العربية أو الإنجليزية — يعيد ترجمة الواجهة فوراً |
| الاتجاه | RTL / LTR — يؤثر على ترتيب العناصر |
| السمة | داكن / فاتح |
| الكثافة | مريح / مضغوط — يصغّر الخطوط والمسافات |
| حجم الخط الأساسي | 16px افتراضي، أو 10px (حيلة 62.5%)، أو قيمة مخصصة |
| معدل التحديث | كم مرة تُقرأ حالة التحديد من Illustrator (افتراضي 700ms) |

**تصدير/استيراد الإعدادات** عبر ملف JSON. **إعادة ضبط كل شيء** يُرجع القيم الافتراضية ويحذف النقاط المخصصة.

> تغيير حجم الخط الأساسي يغيّر كل التحويلات: عند 10px يصبح `5rem = 50px`. هذا مفيد إن كان موقعك يستخدم `html { font-size: 62.5% }`.

## RTL وكلاسات Tailwind المنطقية

عند تفعيل اتجاه RTL في إعدادات الواجهة، يولّد المفتش كلاسات منطقية تلقائياً:

| بدل | يستخدم |
|---|---|
| `ml-4` / `mr-4` | `ms-4` / `me-4` |
| `pl-4` / `pr-4` | `ps-4` / `pe-4` |
| `text-left` / `text-right` | `text-start` / `text-end` |

هذه الكلاسات تتطلب Tailwind CSS 3.3 أو أحدث.

## أسئلة شائعة

**هل تعدّل الإضافة ملفي؟**
لا. كل التعديلات تمر عبر Illustrator نفسه (resize، حجم الخط، إنشاء artboards). لا تكتب أي بيانات تعريفية داخل العناصر.

**هل تعمل بلا إنترنت؟**
نعم بالكامل. التحويلات وقاعدة بيانات Tailwind والألوان كلها محلية. الإنترنت مطلوب فقط لمعاينة HTML المُصدَّر عبر CDN (اختياري).

**هل تدعم التدرّجات؟**
الألوان الصلبة (RGB/CMYK/Spot) تُطابَق بدقة. التدرّجات تُعرض كنوع `gradient` لكن بدون توليد `bg-gradient-*` في هذه النسخة.

**ماذا يحدث عند تحديد عدة عناصر؟**
تبويب التحجيم يطبّق على الأول إلا إن فعّلت "تطبيق على كل المحدد". المفتش يعرض الأول مع تنبيه بتعدد العناصر.

**كيف أوسّع الدعم لإصدار 2024+؟**
عدّل `CSXS/manifest.xml` في سطر `Host Name="ILST" Version="[24.0,27.9]"` إلى `[24.0,99.0]`، ثم أعد التثبيت. قد تحتاج تفعيل `CSXS.12` لـ PlayerDebugMode.
